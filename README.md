# GLOBAL Hair Saloon

An upscale grooming and booking platform for the modern gentleman, built with Next.js, React, Tailwind CSS, and Prisma.

## Features

- **Luxury Design**: High-end aesthetic with custom micro-interactions and dark/copper themes.
- **Dynamic Booking System**: Interactive booking calendar with real-time slot availability.
- **Service Menu**: Detailed service listings with duration and pricing.
- **Lookbook Gallery**: Curated styling portfolio.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS
- **Database ORM**: Prisma
- **Database**: SQLite (for development)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Setup the database (if not already done):
   ```bash
   npx prisma generate
   npx prisma db push
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to view the application.
